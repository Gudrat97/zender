# Zender для Android

Нативное приложение на Kotlin, Jetpack Compose и Media3. Агенты работают прямо на телефоне
и обращаются к Claude API по HTTPS. Ключ API хранится на устройстве в зашифрованном виде.

## Структура

- `core/` — чистый Kotlin/JVM-модуль: цикл агентов, 10 субагентов и оркестратор, инструменты,
  SRT, разбор CSV, проверка качества. Не зависит от Android, тесты запускаются на любой машине.
- `app/` — Android-приложение: экран Compose, HTTP-клиент Claude, `AndroidWorkspace`
  (монтаж через Media3 Transformer, кадры и смены сцен через MediaMetadataRetriever),
  хранение ключа через `EncryptedSharedPreferences`.

## Статус сборки

- `core`: собирается и проходит 16 тестов (`./gradlew :core:test`).
- `app`: код написан по API Media3 1.4.1 и AGP 8.5, но **не скомпилирован**. В среде, где
  готовился проект, Google Maven и Android SDK недоступны. Первая сборка в Android Studio
  может потребовать мелких правок импортов или сигнатур. Поправьте по ошибкам компилятора.

## Сборка и запуск

1. Установите Android Studio (с Android SDK, API 34).
2. Откройте папку `android/` как проект.
3. Дождитесь синхронизации Gradle и нажмите Run на устройстве с Android 9 (API 28) и выше.
4. В приложении введите ключ API Anthropic и нажмите «Сохранить ключ».
5. Добавьте видео, опишите задачу и нажмите «Запустить». Поле «Агент» пустое — запускается
   полный цикл; укажите имя (например `qa`), чтобы вызвать одного агента.

Тесты ядра: `./gradlew :core:test`. Если нужно собрать без `app`: `./gradlew :core:test -Pzender.skipApp=true`.

## Что работает и что нет на Android (версия 0.1)

| Функция | Статус |
|---|---|
| Агенты, оркестратор, тренды, сценарий, аналитика, публикация | ✅ |
| Нарезка, склейка, вертикальный 9:16 (Media3) | ✅ (не проверено на устройстве) |
| Кадры для обложки | ✅ |
| Смены сцен | ⚠️ грубая оценка: 1 кадр в секунду, сравнение яркости |
| Громкость (LUFS) и нормализация | ❌ пока не реализованы, QA сообщит, что громкость не измерена |
| Распознавание речи и субтитры | ❌ нужна интеграция whisper.cpp; SRT-сборка уже готова в `core` |
| Вшивание субтитров в видео | ❌ не реализовано |
| Медиатека | ⚠️ работает внутри папки приложения; импорт и экспорт через системный выбор ещё не сделаны |

Результаты лежат во внутренней папке приложения (`outputs/`). Кнопки «Поделиться» пока нет.

## Безопасность

- Ключ API хранится в Android Keystore через `EncryptedSharedPreferences`, в код и в APK он не попадает.
- Приложение отправляет на API только текст задач и данные, которые агенты сами читают с устройства
  (например, метрики из CSV). Видео на сервер не загружаются.
- Личное использование: ключ остаётся на вашем телефоне. Если приложение будут раздавать другим,
  вызовы Claude API лучше перенести на свой сервер, иначе ключ придётся доверить каждому пользователю.
- Публикацию на TikTok приложение не делает. Готовый черновик и проверку выполняете вы.
